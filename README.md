# Rove

Rove is a task and workflow assistant for getting digital work done. Give it a task, work alongside it when you want to, and continue the conversation later.

This repository hosts official Rove downloads and public issue reports.

## Get Rove

[Download the latest Mac release](https://github.com/Kahmyl/rove-releases/releases/latest).

Rove currently supports **Apple Silicon Macs (M1 or later) running macOS 13 or later**. Connect your eligible ChatGPT account through Codex for model-assisted work. Your account's usage limits apply.

### Install on Mac

1. Download the `.dmg` file from the release.
2. Open the downloaded disk image.
3. Drag Rove into Applications.
4. Open Rove from Applications.
5. Connect your account and start a task.

A ZIP archive and SHA-256 checksums are available with the release.
